Gemini Notes combines a native macOS Electron architecture with strict process sandboxing and direct Google Gemini 2.5 SDK execution.

  • Context Isolation: Renderer runs with contextIsolation: true and nodeIntegration: false.
  • Hardened Local Vault: Notes and snapshots are persisted atomically with 0o600 owner-only permissions.

Defense-in-Depth & Systems Engineering

Hardened Security & Tri-Agent Architecture

Every layer of Gemini Notes—from Electron IPC boundaries to DOM sanitization—was architected and verified through a specialized tri-agent engineering workflow.

Layer 01

Strict CSP & DOM XSS Sanitizer

All AI-generated HTML and rich-text paste buffers pass through a deterministic allowlist sanitizer (src/services/sanitizer.ts) that strips executable scripts, inline event handlers, and unsafe URI schemes before touching the DOM.

Layer 02

Sandboxed IPC & OS Keychain

The Electron renderer runs with contextIsolation: true, nodeIntegration: false, and a strictly typed preload bridge. Gemini API keys are encrypted at rest via macOS Keychain (safeStorage).

Layer 03

Atomic 0o600 Vault Persistence

Local storage files (notes.json, settings.json, and encrypted credentials) enforce strict 0o600 owner-only POSIX file permissions with atomic temp-file write-and-rename durability.
